# Guides

| Guide | Use it when |
|-------|-------------|
| [Appearances](appearances.md) | You choose the shape of the placeholders: lines, circles, squares or your own layout. |
| [Animations](animations.md) | You choose the shimmer or pulse effect, or turn it off. |
| [Theming](theming.md) | You restyle the placeholders with CSS variables or the `theme` input. |
| [Configuration](configuration.md) | You set defaults for the whole application or a route with `provideSkeletonLoader()`. |
| [Loading States](dynamic-content.md) | You swap placeholders and content with `@if`, `@defer` or a custom layout. |
| [Accessibility](accessibility.md) | You want to know what screen readers announce and how to label each loader. |
| [Performance](performance.md) | You render many loaders at once: lists, tables, dashboards. |
