## [22.0.0] - 2026-11-20

First release on the new version scheme: the library's major version tracks Angular's. It replaces the unreleased
`1.0.0-alpha.0` preview.

### ⚠️ Upgrade notes ⚠️

> **Coming from `1.0.0-alpha.0`?** Read [Migrating from 1.0.0-alpha](README.md#migrating-from-100-alpha) (or the
> [migration guide](docs/22.0.0/content/migration/alpha-to-22.md)) before upgrading.

- **Angular 22** — the peer dependencies are `@angular/common` and `@angular/core` `^22.0.0`; `zone.js`, `rxjs` and
  `@angular/platform-browser` are no longer peers.
- **No NgModule** — `SkeletonLoaderModule` and `SkeletonLoaderModule.forRoot()` are removed: import the standalone
  `SkeletonLoaderComponent` and set defaults with `provideSkeletonLoader()`.
- **Provider renamed** — `provideNgxSkeletonLoader()` is now `provideSkeletonLoader()`; nested providers merge over
  their ancestors and `undefined` never overrides.
- **Accessibility markup** — the per-item `role="progressbar"`, `tabindex="-1"`, `aria-valuemin`, `aria-valuemax`,
  `aria-valuetext` and `aria-label` are replaced by one polite `role="status"` region on the host (`aria-busy`,
  `aria-label`), a visually hidden `loadingText` and `aria-hidden` items. Update tests and styles that targeted
  `[role="progressbar"]`.
- **`size` on circles** — `size` now sets the width and height of `circle` items as well as `square` ones.
- **Invalid sizes** — numeric strings that are not a valid size (`'abc'`, `'10em'`) are ignored instead of
  producing `0px`.
- **`custom-content`** — `count` is forced to `1` in production too; a provider `count` no longer applies to it, and development mode logs an error only for a `count` bound on the loader.
- **Keyframes** — renamed from `progress` / `pulse` to `ngx-skeleton-loader-progress` / `ngx-skeleton-loader-pulse`.
- **Items** — rendered as `<span class="skeleton-loader">` instead of `<div>`.

### ✨ Features

- **`provideSkeletonLoader(config)`** — `EnvironmentProviders` for application or route-level defaults of every
  input; precedence is built-in defaults, then providers, then inputs.
- **Configuration exports** — `SKELETON_LOADER_CONFIG` (provided in root, `{}` by default),
  `SKELETON_LOADER_DEFAULTS`, `mergeSkeletonLoaderConfig()` and the `SkeletonLoaderConfig`,
  `SkeletonLoaderAppearance`, `SkeletonLoaderAnimation`, `SkeletonLoaderSize` and `SkeletonLoaderTheme` types.
- **CSS custom properties** — `--ngx-skeleton-loader-color`, `-highlight`, `-highlight-dark`, `-pulse-dark-color`,
  `-height`, `-radius`, `-shape-size`, `-gap` and `-duration`; the `theme` input accepts custom properties too.
- **Theme merging** — `extendsFromRoot: true` in the provider theme merges instance themes over it.
- **Signals** — standalone, `OnPush` component with signal inputs; zoneless-ready.
- **Offscreen loaders stop animating** — one `IntersectionObserver` shared by every loader flags the hosts outside the
  viewport (`data-skeleton-offscreen`, with a 200px margin) and their animations are removed, without change
  detection. With 1000 loaders of 3 lines (Chromium, 4× CPU throttling) the page goes from 6 to 59 fps for `progress`
  and from 12 to 60 fps for `pulse`; without `IntersectionObserver` (server rendering) every loader animates.

### ♿ Accessibility

- **One status region per loader** — announced once whatever the `count`, with a configurable label and loading text.
- **Reduced motion** — every animation stops, and the shimmer is hidden, under `prefers-reduced-motion: reduce`.
- **`announce` input** — `announce="false"` (or `provideSkeletonLoader({ announce: false })`) makes a loader
  decorative (`aria-hidden`, no status role or hidden text), so a region you label yourself announces many loaders
  once instead of every row.

### 🔧 Infrastructure

- **Angular 22.3 and TypeScript 6.0** — workspace built and tested with Angular 22.3 and TypeScript 6.0 (TypeScript 7
  is excluded because Angular 22 requires `>=6.0 <6.1`); Node.js `>=24.15`, Bun `>=1.4`. The published peer range
  stays `^22.0.0`.
- **Vitest 5.1** — specs run with Vitest and jsdom through `@angular/build:unit-test`, replacing Karma and Jasmine.
- **Biome** — linting and formatting with Biome, replacing ESLint; Husky `pre-commit` and `pre-push` hooks.
- **Pipelines** — Azure DevOps pipelines, refreshed GitHub workflows and a Makefile with Trivy security scan targets.
- **Docs** — versioned docs under `docs/22.0.0` with a manifest and search index generated by
  `@fsegurai/manifest-generator`, and Arkodex playground samples.
